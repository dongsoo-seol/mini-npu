# 2단계. 2차원 배열 저장과 조회

## 1. 수행 목표

N×N 배열을 만들고 특정 행·열 위치에 숫자를 저장하거나 조회한다.

필수 크기인 3×3, 5×5, 13×13, 25×25를 검증한다.

## 2. 학습 목표

- 중첩 리스트로 행과 열을 표현한다.
- 위치 번호가 0부터 시작함을 이해한다.
- 클래스의 속성과 메서드를 구분한다.
- 잘못된 위치와 값을 예외로 알린다.
- 자동 검증 결과와 로그를 확인한다.

## 3. 구현 파일

main.py에 Matrix 클래스를 작성했다.

| 구성 | 역할 |
|---|---|
| size | 배열의 행·열 크기 |
| data | 숫자를 보관하는 중첩 리스트 |
| __init__() | 모든 값이 0인 N×N 배열 생성 |
| _check_position() | 행·열 번호의 자료형과 범위 검사 |
| get_value() | 지정 위치의 값 조회 |
| set_value() | 지정 위치에 숫자 저장 |

각 행을 별도로 생성하여 한 행의 변경이 다른 행에 영향을 주지 않도록 했다.

## 4. 입력 자료 검사

구현한 검사 규칙은 다음과 같다.

- 배열 크기는 0보다 큰 정수여야 한다.
- 행과 열 번호는 정수여야 한다.
- 위치는 0부터 size - 1 사이여야 한다.
- 저장 값은 정수 또는 실수여야 한다.
- 문자열, None, bool은 저장 값으로 허용하지 않는다.
- NaN과 양·음의 무한대는 허용하지 않는다.

이 단계에서는 잘못된 요청에 예외를 발생시킨다.
이후 사용자 입력과 JSON 분석에서 이를 안내·재입력 또는 케이스별 FAIL로 연결한다.
## 5. 문법 검사

다음 명령이 오류 없이 끝나는 것을 확인했다.

```powershell
python -m py_compile main.py
```

문법 검사 통과와 실제 기능 검증은 서로 다른 확인 항목이다.

## 6. 3×3 직접 실행 결과

모든 값이 0인 배열을 만들고 가운데 위치인 (1, 1)에 7을 저장했다.

실제 출력:

```text
초기 배열: [[0, 0, 0], [0, 0, 0], [0, 0, 0]]
저장 후 배열: [[0, 0, 0], [0, 7, 0], [0, 0, 0]]
가운데 값: 7
첫 행의 같은 열: 0
```

가운데 값은 변경되고 다른 행의 값은 유지됨을 확인했다.

## 7. 자동 검증

test_matrix.py를 작성하고 다음 명령으로 실행했다.

```powershell
python -m unittest -v test_matrix
```

| 테스트 | 확인 내용 |
|---|---|
| test_required_sizes | 네 크기의 생성, 초기값, 가운데 정수와 마지막 위치의 실수 저장·조회 |
| test_independent_rows | 한 행의 변경이 다른 행에 영향을 주지 않음 |
| test_independent_matrices | 서로 다른 배열이 독립적으로 유지됨 |
| test_invalid_positions | 음수와 범위 밖 위치의 읽기·쓰기 거절 |
| test_invalid_values | 문자열, None, bool, NaN, 무한대 거절 |

5개 테스트가 모두 통과했다.
네 크기는 test_required_sizes 안에서 각각 하위 검증했다.
