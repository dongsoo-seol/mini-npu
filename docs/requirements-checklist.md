# 미션 3 요구사항 체크리스트

## 사용 방법

기능을 구현하고 실제 결과를 확인한 뒤에만 [x]로 변경한다.
확인한 명령, 입력, 출력과 오류 해결 내용은 별도 검증 문서에 기록한다.

## 1. 개발 환경과 구현 조건

- [ ] Python 3.8 이상에서 실행한다.
- [ ] 외부 라이브러리를 사용하지 않는다.
- [ ] Python 표준 라이브러리만 사용한다.
- [x] MAC 계산을 반복문으로 직접 구현한다.
- [ ] main.py를 메인 실행 파일로 제공한다.
## 2. 데이터 구조

- [x] N×N 크기의 2차원 패턴과 필터를 저장한다.
- [x] 특정 행·열 위치에 값을 저장한다.
- [x] 특정 행·열 위치의 값을 조회한다.
- [x] 3×3, 5×5, 13×13, 25×25를 처리한다.
- [x] 배열의 행 수와 각 행의 열 수를 확인한다.
- [x] 정수와 실수 데이터를 계산할 수 있다.
## 3. 모드 선택

- [ ] 실행 시 사용자 입력 모드와 JSON 분석 모드를 선택할 수 있다.
- [ ] 잘못된 메뉴 입력을 안내하고 다시 입력받는다.

## 4. 사용자 입력 모드

- [x] 필터 A를 3개 행으로 입력받는다.
- [x] 필터 B를 3개 행으로 입력받는다.
- [x] 각 행의 숫자는 공백으로 구분한다.
- [x] 두 필터 입력 후 저장된 내용을 출력하여 확인한다.
- [x] 필터 저장 확인 후 3×3 패턴을 입력받는다.
- [x] 열 개수 부족·초과를 안내하고 해당 행을 다시 입력받는다.
- [x] 숫자 변환 실패와 빈 입력을 안내하고 다시 입력받는다.
- [x] 완성된 배열이 3×3인지 확인한다.
- [x] 두 필터의 MAC 점수를 출력한다.
- [x] epsilon을 적용하여 A/B/판정 불가를 출력한다.
- [x] 판정 후 3×3 성능 분석을 출력한다.
## 5. JSON 로드와 검증

- [x] 제공된 원본 data.json을 확보하고 구조를 확인한다.
- [x] data.json은 main.py와 같은 폴더에 배치한다.
- [x] main.py 위치를 기준으로 data.json 경로를 처리한다.
- [x] filters의 size_5, size_13, size_25를 읽는다.
- [x] patterns의 input과 expected를 읽는다.
- [x] size_{N}_{idx} 식별자에서 N을 추출한다.
- [x] N에 맞는 size_N 필터를 선택한다.
- [x] 패턴과 필터가 모두 해당 N×N인지 확인한다.
- [x] 필수 항목 누락과 잘못된 자료 구조를 확인한다.
- [x] 케이스의 구조·크기 오류를 FAIL로 기록한다.
- [x] 한 케이스가 실패해도 다음 케이스를 계속 분석한다.
- [x] 파일 없음이나 JSON 해석 실패를 안내하고 비정상 종료를 방지한다.
## 6. 라벨 정규화와 판정

- [x] expected의 +를 Cross로 정규화한다.
- [x] expected의 x를 X로 정규화한다.
- [x] 필터 키 cross를 Cross로 정규화한다.
- [x] 필터 키 x를 X로 정규화한다.
- [x] JSON 모드의 출력과 expected 비교는 표준 라벨을 사용한다.
- [x] 알 수 없는 라벨은 임의로 바꾸지 않고 오류로 처리한다.
- [x] epsilon 값과 동점 조건을 코드와 README에 명시한다.
- [x] 점수 차이의 절댓값이 epsilon보다 작으면 동점 처리한다.
- [x] 동점 검사를 먼저 하고, 동점이 아니면 높은 점수를 선택한다.
- [x] JSON 판정을 Cross/X/UNDECIDED로 출력한다.
- [x] 판정이 정규화한 expected와 같으면 PASS, 다르면 FAIL로 처리한다.
사용자 입력 모드의 A/B와 JSON 모드의 Cross/X를 구분한다.
사용자가 입력한 필터 A가 반드시 십자가라고 가정하지 않는다.

## 7. 성능 분석

- [x] MAC 함수 호출 구간을 중심으로 시간을 측정한다.
- [x] 입력·출력·파일 읽기·배열 준비 시간을 측정에서 제외한다.
- [x] 크기별 최소 10회 측정한 평균을 구한다.
- [x] 평균 시간은 ms 단위로 출력한다.
- [x] 표에 크기, 평균 시간(ms), 연산 횟수(N²)를 포함한다.
- [x] 사용자 입력 모드에서 3×3 표를 출력한다.
- [x] JSON 모드에서 3×3, 5×5, 13×13, 25×25 표를 출력한다.
- [x] 필터 하나의 MAC 호출을 기준으로 시간과 연산 횟수를 통일한다.
- [x] 별도 측정용 자료 사용 여부를 문서에 명시한다.
| 크기 | 필터 하나의 MAC 횟수 |
|---|---:|
| 3×3 | 9 |
| 5×5 | 25 |
| 13×13 | 169 |
| 25×25 | 625 |

## 8. JSON 결과 리포트

- [x] 케이스 식별자, Cross 점수, X 점수, 판정을 출력한다.
- [x] 정규화한 기대값과 PASS/FAIL을 출력한다.
- [x] 계산 불가 케이스는 가짜 점수 대신 원인을 표시한다.
- [x] 성능 분석 후 전체 테스트 수·통과 수·실패 수를 출력한다.
- [x] 전체 수가 통과 수와 실패 수의 합과 일치한다.
- [x] 검증 오류로 계산하지 못한 케이스도 실패 수에 포함한다.
- [x] 실패 케이스의 식별자와 실패 사유를 요약한다.
- [x] 실패가 없으면 실패 케이스 없음을 명시한다.
- [x] 파일 로드 실패를 정상 분석의 0 FAIL로 표시하지 않는다.

## 9. 실행 순서

- [x] 사용자 모드: 필터 A·B 입력 → 저장 확인 → 패턴 입력 → MAC → 판정 → 3×3 성능 분석
- [x] JSON 모드: 필터 로드 → 패턴 로드·검증 → MAC·판정·PASS/FAIL → 네 크기 성능 분석 → 결과 요약

## 10. 재현성 검증

- [ ] 3×3 십자가 패턴과 십자가 필터의 점수가 5이다.
- [ ] 3×3 십자가 패턴과 X 필터의 점수가 1이다.
- [ ] 3×3 X 패턴과 십자가 필터의 점수가 1이다.
- [ ] 3×3 X 패턴과 X 필터의 점수가 5이다.
- [ ] 정확한 동점과 epsilon보다 작은 점수 차이를 검증한다.
- [ ] 소수가 포함된 MAC 계산을 검증한다.
- [ ] 사용자 입력 오류 후 재입력을 검증한다.
- [ ] JSON 크기 오류 후 다음 케이스 처리를 검증한다.
- [ ] 케이스별 PASS/FAIL과 최종 집계를 대조한다.
