# 3단계. 반복문 기반 MAC 계산

## 1. 수행 목표

입력 패턴과 필터의 같은 위치에 있는 숫자끼리 곱하고, 결과를 모두 더하는 MAC 연산을 구현한다.

외부 라이브러리 없이 Python 반복문으로 계산한다.

## 2. 학습 목표

- 중첩 반복문으로 모든 행과 열을 순회한다.
- 누적 변수에 계산 결과를 더한다.
- 함수의 인수와 반환값을 이해한다.
- 정상 계산과 잘못된 요청을 구분하여 검증한다.
- 문법 검사와 실제 기능 검증을 구분한다.

## 3. 구현 내용

main.py의 Matrix 클래스 아래에 별도 함수 mac_score()를 추가했다.

```python
mac_score(pattern, filter_data)
```

두 인수는 Matrix 객체이며, 같은 크기여야 한다.

처리 순서:

1. 입력 패턴과 필터가 Matrix 객체인지 확인한다.
2. 두 배열의 크기가 같은지 확인한다.
3. 누적값을 0으로 준비한다.
4. 바깥 반복문으로 행을 순회한다.
5. 안쪽 반복문으로 열을 순회한다.
6. 같은 위치의 입력값과 필터값을 곱하여 누적한다.
7. 실수 결과가 NaN이나 무한대이면 오류로 알린다.
8. 최종 점수를 반환한다.

계산 함수 내부에서는 화면 출력이나 파일 읽기를 수행하지 않는다.

## 4. 핵심 계산

```python
total += input_value * filter_value
```

위 코드는 다음과 같은 의미이다.

```text
새 누적값 = 기존 누적값 + 입력값 × 필터값
```

이번 연산은 같은 위치끼리 곱한 뒤 합산하는 계산이다.
일반적인 행렬 곱셈과는 다르다.

## 6. 십자가와 X 검증

자동 검증에서 다음 결과를 확인했다.

| 입력 패턴 | 필터 | 예상값과 일치한 점수 |
|---|---|---:|
| 십자가 | 십자가 | 5 |
| 십자가 | X | 1 |
| X | 십자가 | 1 |
| X | X | 5 |

이 단계에서는 점수 계산만 검증했다.
높은 점수를 선택하는 판정과 epsilon 동점 처리는 다음 단계에서 구현한다.

## 7. 추가 검증

test_mac.py에 7개 테스트를 작성했다.

| 테스트 | 검증 내용 |
|---|---|
| test_cross_and_x_scores | 십자가와 X의 네 조합 |
| test_decimal_and_negative_values | 소수와 음수 계산 결과 -4.5 |
| test_zero_pattern | 입력이 모두 0이면 점수 0 |
| test_required_sizes | 네 크기에서 모든 위치의 계산 |
| test_size_mismatch | 서로 다른 크기의 계산 거절 |
| test_invalid_arguments | Matrix가 아닌 인수 거절 |
| test_nonfinite_result | 큰 실수의 곱으로 생긴 무한대 결과 거절 |

크기별 검증에서는 입력의 모든 값을 1, 필터의 모든 값을 2로 설정했다.

따라서 예상 점수는 2×N×N이다.

| 크기 | 예상 점수 |
|---|---:|
| 3×3 | 18 |
| 5×5 | 50 |
| 13×13 | 338 |
| 25×25 | 1250 |

## 9. 계산량과 복잡도

필터 하나를 적용할 때 N개의 행과 각 행의 N개 열을 순회한다.

따라서 위치별 곱셈과 누적을 N²회 수행하며 시간 복잡도는 O(N²)이다.

| 크기 | 필터 하나의 MAC 횟수 |
|---|---:|
| 3×3 | 9 |
| 5×5 | 25 |
| 13×13 | 169 |
| 25×25 | 625 |

두 필터를 적용하면 계산량은 늘지만 필터 수가 고정되어 있으므로 시간 복잡도는 O(N²)이다.

현재 기록한 테스트 실행 시간은 성능 분석용 MAC 평균 시간이 아니다.
크기별 10회 이상 측정과 ms 평균 표는 이후 성능 분석 단계에서 구현한다.

## 10. 현재 구현 범위

완료한 기능:

- Matrix 배열 관리
- 반복문 기반 MAC 점수 계산
- 계산 요청의 자료형과 크기 확인
- 배열과 MAC 자동 검증

아직 구현하지 않은 기능:

- 라벨 정규화와 epsilon 판정
- 사용자 입력과 재입력
- JSON 구조 검증과 케이스별 분석
- 크기별 성능 측정
- 전체 결과 리포트

현재 함수에서 발생시키는 예외는 이후 입력 안내와 케이스별 FAIL 처리에 연결한다.
