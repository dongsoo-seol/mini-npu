# Mini NPU 시뮬레이터

## 1. 프로젝트 개요

코디세이 미션 3 과제로 만드는 Python 콘솔 프로그램입니다.

입력 패턴과 필터의 같은 위치에 있는 숫자끼리 곱한 뒤 모두 더하는 MAC 연산을 직접 구현합니다.

사용자 입력과 JSON 데이터를 분석하고, 필터 점수를 비교하여 판정 결과와 성능 분석 자료를 출력할 예정입니다.

이 프로그램은 MAC 계산 원리를 학습하는 시뮬레이터이며, 실제 NPU 하드웨어의 병렬 처리 성능을 재현하지는 않습니다.

## 2. 개발 환경

- 운영 환경: Windows PowerShell
- Python: 3.12.10
- Git: 2.56.0.windows.4
- 과제 조건: Python 3.8 이상
- 외부 라이브러리 사용 금지
- Python 표준 라이브러리만 사용

Python 버전과 다음 명령의 정상 실행을 확인했습니다.

```powershell
python -c "print('Mini NPU 준비 완료')"
```

## 3. 구현할 기능

### 데이터 구조와 MAC 계산

- N×N 크기의 2차원 패턴과 필터 저장
- 특정 위치의 값 저장과 조회
- 3×3, 5×5, 13×13, 25×25 처리
- 반복문을 사용한 위치별 곱셈과 누적 합산
- 정수와 실수 데이터 처리
- NumPy, pandas 등 외부 라이브러리 사용 금지

### 사용자 입력 모드

다음 순서로 동작하도록 구현합니다.

1. 필터 A 입력
2. 필터 B 입력
3. 저장된 필터 내용 확인
4. 패턴 입력
5. MAC 점수 계산
6. A/B/판정 불가 출력
7. 3×3 성능 분석 출력

입력은 각 행의 숫자를 공백으로 구분하는 방식으로 받습니다.

행·열 개수와 숫자 변환을 검증하고, 오류가 있으면 안내 후 재입력을 유도합니다.

### JSON 분석 모드

다음 순서로 동작하도록 구현합니다.

1. data.json에서 필터 로드
2. 패턴 로드와 구조·크기 검증
3. 케이스별 MAC 점수와 판정 출력
4. expected와 비교하여 PASS/FAIL 출력
5. 네 크기의 성능 분석 출력
6. 전체 결과와 실패 사유 요약

패턴 식별자에서 크기 N을 추출하여 해당 size_N 필터를 선택합니다.

케이스의 구조나 크기가 잘못되면 원인을 기록하고 FAIL 처리한 뒤 다음 케이스를 계속 분석합니다.

## 4. 판정 정책

JSON 분석에서는 표준 라벨 Cross와 X를 사용합니다.

- expected의 +는 Cross로 변환
- 필터 키 cross는 Cross로 변환
- expected와 필터 키의 x는 X로 변환

점수 비교에는 epsilon을 사용합니다.

계획한 기준은 다음과 같습니다.
```text
epsilon = 1e-9
abs(점수 A - 점수 B) < epsilon이면 동점
```

사용자 입력 모드의 동점은 판정 불가로 표시합니다.

JSON 모드의 동점은 UNDECIDED로 표시하며, 정규화한 expected와 비교하여 PASS/FAIL을 결정합니다.

## 5. 성능 분석 계획

MAC 함수 호출 구간을 크기별 최소 10회 측정하고 평균 시간을 ms로 출력합니다.

파일 읽기, 사용자 입력, 배열 준비와 화면 출력은 측정 구간에서 제외합니다.

성능 표는 필터 하나를 한 번 적용하는 MAC 계산을 기준으로 작성합니다.

| 크기 | 평균 시간(ms) | MAC 횟수(N²) |
|---|---|---:|
| 3×3 | 구현 후 측정 | 9 |
| 5×5 | 구현 후 측정 | 25 |
| 13×13 | 구현 후 측정 | 169 |
| 25×25 | 구현 후 측정 | 625 |

## 6. 실행 방법

현재 main.py에는 배열을 관리하는 Matrix 클래스와 반복문 기반 MAC 계산 함수 mac_score()를 구현했습니다.
최종 메뉴와 분석 실행 흐름은 아직 구현하지 않았습니다.

배열 기능은 다음 명령으로 검증할 수 있습니다.

python -m unittest -v test_matrix test_mac

구현 후 다음 명령으로 실행하도록 구성할 예정입니다.

```powershell
python main.py
```프로그램 시작 시 사용자 입력 모드와 JSON 분석 모드를 선택하도록 구현합니다.

data.json은 과제에서 제공한 원본을 확보한 뒤 main.py와 같은 폴더에 배치합니다.

파일 경로는 main.py의 위치를 기준으로 처리할 예정입니다.

## 8. 결과 리포트

배열 관리와 MAC 계산은 구현하고 검증했습니다. JSON 데이터 분석과 성능 측정은 아직 수행하지 않았습니다.
실제 실행 후 다음 내용을 포함하여 최소 10줄 이상 작성합니다.

- 전체 테스트 수, 통과 수, 실패 수
- 실패 케이스 식별자와 원인
- 실패가 없다면 0 FAIL이 된 근거
- 라벨 정규화와 epsilon 정책의 영향
- 성능 측정 조건과 크기별 결과 해석
- N² 연산 횟수와 O(N²) 시간 복잡도의 근거
- 구현과 측정의 한계

결과를 미리 성공으로 작성하지 않고 실제 실행 결과를 기록합니다.
