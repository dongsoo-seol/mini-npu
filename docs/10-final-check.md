# 10단계. 최종 문서와 제출 파일 점검

## 1. 점검 목적

구현한 프로그램, README와 검증 자료가 서로 일치하는지 확인한다.

제출 준비와 실제 제출·평가 완료를 구분하여 기록한다.

## 2. 실행 환경과 제출 구성

- 요구 환경: Python 3.8 이상
- 실제 검증 환경: Python 3.12.10
- 외부 라이브러리 사용 없음
- MAC 연산은 반복문으로 직접 구현
- 실행 명령: python main.py

제출 구성:

| 파일 | 역할 |
|---|---|
| main.py | 메인 실행 파일 |
| README.md | 실행 방법·구현 정책·재현 방법·결과 리포트 |
| data.json | 실행에 필요한 제공 원본 |
| test_*.py | 자동 검증 보조 자료 |
| docs | 단계별 수행 기록·검증 로그·측정 결과 |

기본 실행에 필요한 main.py와 data.json만 임시 폴더에 복사한 실행도 자동 검증에서 확인했다.

## 3. 기능과 재현성 확인

### 사용자 입력 모드

확인한 순서:

```text
메뉴 1 선택
→ 필터 A·B 입력
→ 저장 내용 확인
→ 패턴 입력
→ MAC 점수와 판정
→ 3×3 성능 표
→ 메뉴 복귀
```

필터 A가 십자가, 필터 B가 X이고 패턴이 십자가일 때:

```text
필터 A MAC 점수: 5
필터 B MAC 점수: 1
판정 결과: A
```

숫자 개수 오류, 문자, 빈 입력, NaN과 무한대의 처리도 검증했다.

### JSON 분석 모드

확인한 순서:

```text
메뉴 2 선택
→ 필터·패턴 읽기와 검증
→ 케이스별 결과
→ 네 크기의 성능 표
→ 전체 집계와 실패 목록
→ 메뉴 복귀
```

구조·크기 오류가 있는 케이스를 FAIL로 처리하고 다음 케이스를 계속 분석하는 것을 검증했다.

파일 전체 오류는 안내 후 메뉴로 돌아오며, 정상 분석의 0 FAIL로 표시하지 않는다.

## 4. 원본 분석 결과

전체 6개, PASS 3개, FAIL 3개이다.

| 실패 케이스 | 원인 |
|---|---|
| size_5_1 | epsilon 기준 동점과 기대값 X의 불일치 |
| size_13_2 | epsilon 기준 동점과 기대값 Cross의 불일치 |
| size_25_1 | epsilon 기준 동점과 기대값 X의 불일치 |

라벨을 Cross/X로 정규화하고, 점수 차이의 절댓값이 1e-9보다 작으면 UNDECIDED로 처리했다.

원본은 0 FAIL이 아니므로 실제 세 실패의 원인을 README에 분석했다.

PASS 수를 늘리기 위해 원본 데이터나 비교 정책을 변경하지 않았다.

## 5. 성능 결과 대조

기준 측정 파일:

```text
docs/08-performance-results.json
```

README에 기록한 값:

| 크기 | 평균 시간(ms) | MAC 횟수 | 측정 횟수 |
|---|---:|---:|---:|
| 3×3 | 0.011840 | 9 | 10 |
| 5×5 | 0.028900 | 25 | 10 |
| 13×13 | 0.183770 | 169 | 10 |
| 25×25 | 1.154100 | 625 | 10 |

표는 모든 값이 1.0인 공통 측정용 배열의 기록이다.

사용자 모드에서는 실제 입력 패턴과 필터 A를 측정한다.

준비 실행 1회는 제외하고 이후 10회의 평균을 사용한다.

입력·출력·파일 읽기·배열 준비는 측정에서 제외하며, MAC 함수 내부의 검사와 조회 비용은 포함한다.

필터 하나의 MAC 시간 복잡도는 O(N²)이다.
고정된 두 필터를 적용해도 O(N²)이다.

실제 시간은 환경에 따라 달라지므로 동일한 시간값의 재현을 요구하지 않는다.

## 8. 확인 범위와 한계

Python 3.12.10에서 실행을 검증했으며 Python 3.8 자체에서 별도 실행한 것은 아니다.

KeyboardInterrupt는 자동 검사에서 모의했다.
이를 실제 키보드의 Ctrl+C 조작을 직접 확인한 것으로 기록하지 않는다.

프로그램은 MAC 원리를 학습하는 시뮬레이터이며 실제 NPU 성능 재현이나 필터 학습을 수행하지 않는다.

테스트 통과가 평가 통과를 보장하지는 않는다.
실제 제출 접수와 평가 결과는 평가 사이트에서 별도로 확인한다.
