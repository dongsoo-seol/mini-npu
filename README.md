# Mini NPU 시뮬레이터

## 1. 프로젝트 개요

코디세이 미션 3 과제로 만드는 Python 콘솔 프로그램입니다.

입력 패턴과 필터의 같은 위치에 있는 숫자끼리 곱한 뒤 모두 더하는 MAC 연산을 직접 구현합니다.

사용자 입력과 JSON 데이터를 분석하고, 필터 점수를 비교하여 판정 결과와 성능 분석 자료를 출력할 예정입니다.

이 프로그램은 MAC 계산 원리를 학습하는 시뮬레이터이며, 실제 NPU 하드웨어의 병렬 처리 성능을 재현하지는 않습니다.

## 3. 구현할 기능

### 데이터 구조와 MAC 계산

- N×N 크기의 2차원 패턴과 필터 저장
- 특정 위치의 값 저장과 조회
- 3×3, 5×5, 13×13, 25×25 처리
- 반복문을 사용한 위치별 곱셈과 누적 합산
- 정수와 실수 데이터 처리
- NumPy, pandas 등 외부 라이브러리 사용 금지

### 사용자 입력 모드

다음 순서로 동작하도록 구현합니다.

1. 필터 A 입력
2. 필터 B 입력
3. 저장된 필터 내용 확인
4. 패턴 입력
5. MAC 점수 계산
6. A/B/판정 불가 출력
7. 3×3 성능 분석 출력

입력은 각 행의 숫자를 공백으로 구분하는 방식으로 받습니다.

행·열 개수와 숫자 변환을 검증하고, 오류가 있으면 안내 후 재입력을 유도합니다.

### JSON 분석 모드

다음 순서로 동작하도록 구현합니다.

1. data.json에서 필터 로드
2. 패턴 로드와 구조·크기 검증
3. 케이스별 MAC 점수와 판정 출력
4. expected와 비교하여 PASS/FAIL 출력
5. 네 크기의 성능 분석 출력
6. 전체 결과와 실패 사유 요약

패턴 식별자에서 크기 N을 추출하여 해당 size_N 필터를 선택합니다.

케이스의 구조나 크기가 잘못되면 원인을 기록하고 FAIL 처리한 뒤 다음 케이스를 계속 분석합니다.

## 4. 판정 정책

JSON 분석에서는 표준 라벨 Cross와 X를 사용합니다.

- expected의 +는 Cross로 변환
- 필터 키 cross는 Cross로 변환
- expected와 필터 키의 x는 X로 변환

점수 비교에는 epsilon을 사용합니다.

구현하고 검증한 기준은 다음과 같습니다.
```text
epsilon = 1e-9
abs(점수 A - 점수 B) < epsilon이면 동점
```

사용자 입력 모드의 동점은 판정 불가로 표시합니다.

JSON 모드의 동점은 UNDECIDED로 표시하며, 정규화한 expected와 비교하여 PASS/FAIL을 결정합니다.

## 5. 성능 분석

필터 하나의 MAC 함수 호출을 크기별 10회 측정한 1회 평균이다.

| 크기 | 평균 시간(ms) | 연산 횟수(N^2) | 측정 횟수 |
|---|---:|---:|---:|
| 3x3 | 0.011840 | 9 | 10 |
| 5x5 | 0.028900 | 25 | 10 |
| 13x13 | 0.183770 | 169 | 10 |
| 25x25 | 1.154100 | 625 | 10 |

위 표는 모든 값이 1.0인 공통 측정용 배열을 사용한 기록이다.
사용자 입력 모드에서는 실제 입력 패턴과 필터 A를 측정한다.
준비 실행 1회는 평균에서 제외하고, 이후 10회만 측정했다.
배열 준비, 파일 읽기, 사용자 입력과 화면 출력은 측정 구간에서 제외했다.
MAC 함수 내부의 검사와 값 조회 비용은 호출 시간에 포함된다.
측정값은 실행 환경과 컴퓨터 상태에 따라 달라질 수 있다.

측정 원본: [저장된 성능 결과](docs/08-performance-results.json)

## 8. 결과 리포트

### 원본 데이터 분석 결과

| 케이스 | Cross 점수 | X 점수 | 판정 | 기대값 | 결과 |
|---|---:|---:|---|---|---|
| size_5_1 | 0.9 | 0.8999999999999999 | UNDECIDED | X | FAIL |
| size_5_2 | 8.9 | 0.1 | Cross | Cross | PASS |
| size_13_1 | 0.3 | 14.700000000000008 | X | X | PASS |
| size_13_2 | 7.499999999999997 | 7.5 | UNDECIDED | Cross | FAIL |
| size_25_1 | 4.9 | 4.899999999999999 | UNDECIDED | X | FAIL |
| size_25_2 | 52.9 | 0.1 | Cross | Cross | PASS |

### 실패 원인과 시간 복잡도 분석

1. 제공된 data.json의 패턴 6개를 분석하여 PASS 3개, FAIL 3개를 확인했다.
2. 전체 수 6은 통과 수 3과 실패 수 3의 합과 일치한다.
3. expected의 +와 x를 각각 Cross와 X로 정규화하고, 필터 이름도 표준 라벨로 통일했다.
4. 정규화는 같은 의미를 다른 문자열로 표현하여 발생하는 잘못된 비교를 방지한다.
5. 점수 차이의 절댓값이 1e-9보다 작으면 UNDECIDED로 처리했다.
6. size_5_1은 두 점수가 epsilon 이내로 가까워 동점이 되었고, 기대값 X와 달라 FAIL이다.
7. size_13_2도 두 점수가 epsilon 이내로 가까워 동점이 되었고, 기대값 Cross와 달라 FAIL이다.
8. size_25_1 역시 두 점수가 epsilon 이내로 가까워 동점이 되었고, 기대값 X와 달라 FAIL이다.
9. 나머지 세 케이스는 점수 비교로 선택한 표준 라벨이 기대값과 일치하여 PASS이다.
10. 이번 원본 분석에서는 구조 오류나 계산 불가로 실패한 케이스는 없었다.
11. 세 FAIL은 요구된 동점 정책과 기대값의 불일치 결과이며, PASS를 늘리기 위해 원본이나 epsilon을 바꾸지 않았다.
12. 필터 하나의 MAC 계산은 N개 행과 각 행의 N개 열을 순회하므로 N²회의 곱셈·누적을 수행하며 시간 복잡도는 O(N²)이다.
13. 두 필터를 적용하면 계산량은 늘지만 필터 개수가 고정되어 있으므로 시간 복잡도는 O(N²)이다.
14. 동일한 1.0 값의 측정용 배열을 크기별 10회 측정했으며, 크기가 커질수록 평균 시간이 증가했다.
15. 크기별 실제 시간 비율은 연산 횟수 N^2의 비율과 정확히 같지 않으며, Python 실행 비용과 측정 환경의 영향을 받는다.
16. 배열 준비와 입출력은 측정에서 제외했지만 MAC 함수 내부의 검사와 값 조회 비용은 포함했다.

## 12. 4단계 정규화와 판정 검증 결과

normalize_label()과 compare_scores()를 구현했습니다.

### 라벨 정규화

앞뒤 공백을 제거하고 대소문자 차이를 처리한 뒤 표준 라벨로 변환합니다.

- +, cross, Cross → Cross
- x, X → X
- 알 수 없는 라벨 → 오류로 안내

UNDECIDED는 모양 라벨이 아니라 판정 보류 상태입니다.

### 점수 비교 정책

기본 epsilon은 1e-9입니다.

abs(score_a - score_b) < epsilon이면 UNDECIDED를 반환합니다.

차이가 epsilon과 같으면 동점이 아닙니다.
동점이 아니면 높은 점수에 따라 A 또는 B를 반환합니다.

사용자 입력 모드에서는 A/B/판정 불가로 표시하도록 연결하고 검증했습니다.
JSON 모드에서는 Cross 점수를 첫 번째, X 점수를 두 번째로 전달하여 결과를 Cross/X/UNDECIDED로 연결할 예정입니다.

### 검증 결과

별칭, 공백, 대소문자, 정확한 동점, 근소한 점수 차이, epsilon 경계와 잘못된 값의 거절을 확인했습니다.

## 14. 6단계 JSON 준비 기능 검증 결과

### 처리 방식

main.py와 같은 폴더의 data.json을 UTF-8 BOM까지 처리하여 읽습니다.

최상위 구조와 filters·patterns 항목을 확인합니다.

케이스 식별자에서 N을 추출하여 해당 size_N 필터를 선택합니다.

패턴과 필터의 행·열 개수, 숫자 값, 라벨과 필수 항목을 검사한 뒤 Matrix로 변환합니다.

필터 라벨은 Cross/X로 정규화하며, 정규화 후 중복이나 필터 누락을 거절합니다.

### 원본으로 확인한 내용

원본에는 크기별 필터 3묶음과 패턴 6개가 있습니다.

size_5_1을 준비한 결과는 크기 5, 필터 이름 Cross/X, 정규화한 기대값 X였습니다.

원본 파일을 수정하지 않고 계산용 자료를 준비했습니다.
