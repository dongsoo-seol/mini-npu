# 5단계. 3×3 사용자 입력과 재입력 처리

## 1. 수행 목표

필터 A와 B를 입력받아 저장 내용을 확인한 뒤, 패턴을 입력받아 MAC 계산과 판정을 수행한다.

잘못된 행은 안내하고 다시 입력받는다.

## 2. 학습 목표

- 입력 문자열을 공백으로 분리한다.
- 숫자 개수와 숫자 변환을 검증한다.
- 오류가 있는 행만 다시 입력받는다.
- 기존 입력·계산·판정 함수를 연결한다.
- 실행 순서와 출력 결과를 검증한다.

## 3. 구현 내용

main.py에 다음 함수를 추가했다.

| 함수 | 역할 |
|---|---|
| read_matrix() | 배열을 행 단위로 입력받고 검증 |
| print_matrix() | 저장된 배열을 행 단위로 출력 |
| run_manual_mode() | 필터 입력부터 점수 계산과 판정까지 연결 |

기존 Matrix, mac_score(), compare_scores()를 재사용했다.

## 4. 행 입력과 검증

read_matrix()의 처리 순서는 다음과 같다.

1. 입력받을 크기의 Matrix를 만든다.
2. 한 행을 문자열로 입력받는다.
3. split()으로 공백 기준 분리한다.
4. 항목 수가 크기와 같은지 확인한다.
5. float()로 숫자를 변환한다.
6. NaN과 무한대가 아닌지 확인한다.
7. 정상 행을 저장하고 다음 행으로 이동한다.
8. 모든 행을 받은 뒤 Matrix를 반환한다.

오류가 발생하면 해당 행만 다시 입력받는다.
이미 정상 입력한 이전 행은 유지한다.

## 5. 직접 확인한 재입력 결과

여러 행을 한 줄로 합쳐 입력했을 때 숫자 개수 오류가 안내되었다.

다시 한 행씩 입력하여 정상 배열을 저장했다.

문자와 빈 입력도 확인했다.

```text
1행: 0 1 0
2행: 1 abc 1
입력 형식 오류: 각 줄에 3개의 숫자를 공백으로 구분해 입력하세요.
2행:
입력 형식 오류: 각 줄에 3개의 숫자를 공백으로 구분해 입력하세요.
2행: 1 1 1
3행: 0 1 0
```

저장 결과:

```text
[[0.0, 1.0, 0.0], [1.0, 1.0, 1.0], [0.0, 1.0, 0.0]]
```

입력을 float로 변환하므로 정수 입력도 1.0처럼 저장될 수 있다.

## 6. 사용자 입력 분석 연결

현재 구현한 실행 순서:

```text
필터 A 입력
→ 필터 B 입력
→ 저장된 필터 A·B 출력
→ 패턴 입력
→ MAC 점수 계산
→ epsilon 판정
→ 결과 출력
```

직접 실행한 명령:

```powershell
python -c "from main import run_manual_mode; run_manual_mode()"
```

실제 입력:

- 필터 A: 3×3 십자가
- 필터 B: 3×3 X
- 패턴: 3×3 십자가

실제 결과:

```text
=== 사용자 입력 분석 결과 ===
필터 A MAC 점수: 5
필터 B MAC 점수: 1
판정 결과: A
```

필터 저장 확인이 패턴 입력보다 먼저 출력되는 것도 확인했다.

## 7. 판정과 계산 오류

compare_scores()의 결과를 다음과 같이 표시한다.

| 내부 결과 | 사용자 화면 |
|---|---|
| A | A |
| B | B |
| UNDECIDED | 판정 불가 |

사용자 입력 필터 A가 반드시 십자가라고 가정하지 않는다.

유한한 실수를 입력했더라도 곱셈 결과가 무한대가 될 수 있다.
이 경우 계산 오류를 안내하고 해당 분석을 마친다.
## 8. 자동 검증

test_input.py에 7개 테스트를 작성했다.

| 테스트 | 확인 내용 |
|---|---|
| test_read_valid_values | 공백·소수·음수 입력 |
| test_read_invalid_values | 개수 오류·문자·빈 입력·NaN·무한대 재입력 |
| test_read_interrupted | 중단된 입력을 완성된 배열로 반환하지 않음 |
| test_manual_decisions | 십자가·X·필터 순서 교환·동점 |
| test_manual_output_order | 필터 저장 확인과 패턴 입력의 순서 |
| test_manual_epsilon | 실제 MAC 점수에 epsilon 적용 |
| test_manual_calculation_error | 무한대 계산 결과 안내 |

자동 검증은 입력을 모의하여 실행했다.

입력 중단 검사는 예외가 전달되는지 확인한 것이다.
프로그램 전체의 중단 안내와 종료 처리는 최종 실행 흐름에서 연결한다.
